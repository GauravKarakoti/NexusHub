# Contributing to NexusHub

First off, thank you for considering contributing to NexusHub! It's people like you that make open-source software such a great community. 

## 🧠 How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an issue in the repository. Include as much detail as possible:
* A clear and descriptive title.
* Steps to reproduce the issue.
* Expected vs. actual behavior.
* Screenshots or error logs if applicable.

### Suggesting Enhancements
Have an idea for a new feature or an improvement? We'd love to hear it! Open an issue and use the `enhancement` label. Describe how the feature works and why it would be beneficial to the platform.

### Code Contributions

1. **Fork the Repository:** Create your own fork of `GauravKarakoti/NexusHub`.
2. **Clone your Fork:**
   ```bash
   git clone [https://github.com/YOUR_USERNAME/NexusHub.git](https://github.com/YOUR_USERNAME/NexusHub.git)
   ```
3. Create a Branch: Create a new branch for your feature or bug fix.
```bash
git checkout -b feature/your-feature-name
# or
git checkout -b fix/your-bug-fix
```
4. Make your Changes: Write clean, modular, and well-documented code.

5. Follow Coding Standards:
  - We use TypeScript heavily. Ensure proper typing for all new functions and components.
  - Run the linter (npm run lint) and formatter (npm run format) before committing.

6. Commit your Changes: Use conventional commit messages.
```bash
git commit -m "feat: add user authentication via NextAuth"
```
7. Push to your Fork:
```bash
git push origin feature/your-feature-name
```
8. Submit a Pull Request: Open a PR against the main branch of the original repository. Provide a detailed description of your changes and link any related issues.

## 🧪 Testing
Please ensure that your changes do not break existing functionality. If you are adding a new feature, include relevant unit or integration tests where applicable.

Thank you for contributing to NexusHub!
